Exam Examples

Practice exams for Knowledge of theoretical concepts II (written code analysis). Each version contains a code fragment (index.html, styles.css, app.js) and 30 multiple-choice questions with feedback.

Scoring: 9 points shared equally across 30 questions + 1 base point = 10 points maximum.

  • Version 1 - Event registration (forms, accessibility, CSS, validation, DOM)
  • Version 2 - Product catalog (CSS Grid, filter/map/reduce, DOM rendering)
  • Version 3 - Tabbed interface (sticky layout, Flexbox, events, ARIA)
  • Version 4 - Task list (ES6 class, localStorage, closures, validation)
